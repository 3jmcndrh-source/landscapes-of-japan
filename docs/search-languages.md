# 見た目から探す — 言語ごとの実力

測定: `node scripts/eval-mclip-languages.mjs` / 2026-09-08

## 方式

2段構えになっている。

1. **概念語** (26語 + 2語の組み合わせ325通り)。ビルド時に文と画像の近さを計算済み。
   モデルの読み込みは不要で、25言語すべてで同じように動く。
   「霧のかかった山」のような、語彙の範囲内の複合表現はここで処理する。
2. **自由文** (語彙に無い表現)。`sentence-transformers/clip-ViT-B-32-multilingual-v1`
   (Apache-2.0) をブラウザへ遅延読み込みし、入力文を512次元へ変換して写真と比べる。
   入力文は端末の中だけで処理し、外部へ送らない。
