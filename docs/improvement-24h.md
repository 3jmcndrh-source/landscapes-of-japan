Chrome 拡張 (claude-in-chrome) は本セッションで未接続 (`list_connected_browsers` が空)。

### B-1. フォントの先読みを必要な分だけにした ✔採用

**問題 (実測)**: `next/font` は既定で、宣言した書体の分割片を全部 `<link rel="preload" as="font">` にする。
和文の Zen Kaku Gothic New は Google Fonts 側で **242面** に切られており、
**どのページでも 120ファイル・1,378KB を先読み**していた。写真より先に、高優先度で。

**変更**: `app/[lang]/layout.js` の `Zen_Kaku_Gothic_New({...})` に `preload: false` を1行。
Playfair (Latin・8面・見出しでLCPになりやすい) は先読みを残す。

**測定条件**: 隔離配信 (`scratchpad/serve2.mjs`、帯域無制限)、内蔵ブラウザペイン (HTTPキャッシュが効かない = 毎回コールド)、
`/ja/explore` を1回読み込み。サーバ側の送出バイト数で計測。**このサーバは圧縮しないので JS/CSS は展開後の値**。
フォント (woff2) は元から圧縮済みなので、この値が本番の実転送と同じ。

| | 変更前 | 変更後 | 差 |
|---|---|---|---|
| フォント | **1,454 KB (122ファイル)** | **182 KB (14ファイル)** | **−1,272 KB / −108ファイル** |
| HTML | 91 KB | 62 KB | −29 KB (preloadタグ120本ぶんの markup) |
| JS (未圧縮) | 1,040 KB | 1,040 KB | 変化なし |
| CSS (未圧縮) | 239 KB | 239 KB | 変化なし |
| **合計 / リクエスト数** | **2,848 KB / 147** | **1,548 KB / 39** | **−1,300 KB / −108リクエスト** |

preload の本数は `/ja` `/ja/explore` `/en/explore` `/ar/explore` すべてで **122 → 2**。

**画質・表示の確認 (回帰)**

| 言語 | 結果 |
|---|---|
| ja | `document.fonts.check('40px "Zen Kaku Gothic New"', ...)` が かな・漢字・Latin すべて true。必要な22面が loaded。CLS **0** |
| en | Zen Kaku の Latin面 (U+0-FF, weight 500) が loaded = 従来どおりこの書体で描画。CLS **0** |
| ar (RTL) | `dir=rtl` 維持、横スクロールなし、CLS **0**。アラビア文字は元からこの書体に無くシステム書体 (変更なし) |

`display:"swap"` と `adjustFontFallback` (next/font の既定) が効いているため、文字が消える時間は無く、
実測 CLS も 0。スクリーンショットでも和文が従来のゴシックで表示されることを確認。

**再発防止**: `scripts/check-pages.mjs` に「フォントの先読みが必要最小限 (8ファイル以下)」を追加。
超えたら公開前に落ちる。あわせて初期JSの表示を **実転送 (gzip後) / 展開後** の両方に変更
(従来の「907 KB」は展開後の値で、実際に流れるのは 306 KB)。
