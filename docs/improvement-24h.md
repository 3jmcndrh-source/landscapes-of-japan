### C-1. 採用した対策: 配信ファイル自体を gzip にし、Worker で戻す ✔採用

量子化済みの ONNX でも **gzip で 67%** になる (実測)。

**検討して捨てた案**: `_headers` で `Content-Encoding: gzip` を付ける。
プレビュー配信 (`compression-probe` ブランチ) で実測したところ、
Cloudflare が**さらにもう一度 gzip して**返した (1,460,339 → 1,460,807 バイト、
`curl --compressed` で1層ほどいても元に戻らない)。**本番に出す前に落とせた。**

**採用**: 中身を gzip にしたファイルをそのまま置き、Worker が `DecompressionStream("gzip")` で戻す。
プレビュー配信で `.gz` / 未知の拡張子 / `.bin` のいずれでも Pages がバイト列をそのまま返すことを確認済み。

| Dense | 1.50 MB | 1.39 MB | −0.11 MB |
| 語彙 | 0.95 MB (本番は br 済み) | 0.52 MB | − |
| **モデル関連の合計** | **131.6 MB** | **88.1 MB** | **−43.5 MB (−33%)** |
| 画面の案内 | 「(141 MB)」 | 「**(91 MB)**」 | 実際に流れる量に合わせた |

本番換算 (実行部の br 圧縮も込み): 約 **133.9 MB → 約 90.9 MB (−43 MB / −32%)**。

### D-2. 直した不具合: Lightbox の「操作を隠す」が機能していなかった ✔採用

**症状 (実測)**: Lightbox で「操作を隠す」を押すと
- 閉じるボタンと下部の操作列が**消えない**
- 代わりに出る「操作を表示」(36×36, `z-index:6`) が、閉じるボタン (42×42, `z-index:301`) に
  **28×32px 覆われる**。`document.elementFromPoint` を中心・左下で試すと**どちらも「閉じる」**が返る
- → 元に戻そうとして押すと Lightbox が閉じる。**操作非表示から正常に戻れない**

**原因**: `hidden={bare}` を使っているのに、`.cin-lb-close` と `.cin-lb-bottom` が
`display:flex` を宣言していた。ブラウザ既定の `[hidden]{display:none}` は
クラスの display 宣言に**負ける**ため、`hidden` が無効化されていた。
`.cin-lb-info` は display 宣言が無いので効いており、キャプションだけ消えていた。

**確認**: `document.visibilityState === "visible"` の状態で計測。
アニメーション凍結による見かけ上の問題ではない。

**直し方**: 個別に直すと同じ間違いが再発するので、`app/globals.css` の先頭で
`[hidden]{display:none!important}` を1回だけ宣言。
`hidden={...}` を使っている他の9箇所 (`.ex-panel` / `.lm-menu` / `.sh-menu` /
`.ex-sec-panel` ほか) は display 宣言が無く元から効いていたので、影響なし。

**再発防止**: `check-pages.mjs` に「出力CSSに `[hidden]{display:none!important}` があること」を追加。

### C-2. モデルURLに版を付ける ✔採用 (A3 の「更新時に古い実体が混ざらない」への対応)

`_headers` で `/models/*` を30日キャッシュしているのに、ファイル名は
`model.onnx.000.gz` のまま固定だった。モデルを入れ替えると
**URLは同じで中身だけ変わる**ため、HTTPキャッシュを持っている人には
最大30日間 古い実体が返り、新しいコードと混ざる恐れがあった。

取得URLを `…/model.onnx.000.gz?v=gz-90351278-1460339-547105` の形にした。
版はファイルの大きさから作るので、モデルを入れ替えれば必ず変わる。
Pages の `_headers` はクエリを見ないのでキャッシュ規則はそのまま効く。

**確認**: Cache Storage の項目が `model.onnx.000.gz?v=gz-…` で9件そろい、
再読み込み後の検索で `/models/` の転送が **0件**。結果も「窓に映る街並み」46枚 /
「雪の島」37枚 と変更前に一致。

なお、万一 配信側が勝手に展開して返すようになった場合は、
C-1 で入れた「展開後の大きさが目次と合わなければ使わない」で止まる。
